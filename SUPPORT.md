# Support

Use GitHub Discussions for setup questions and conceptual RAM questions. Use Issues for reproducible defects and focused feature requests. Use private vulnerability reporting for security problems.

When reporting a defect, include the macOS version, Mac model/chip, Memory Widget version, the exact visible behavior, and relevant diagnostics from:

```text
~/Library/Application Support/Memory Widget/Context Observatory/diagnostics.log
```

Remove personal screen, camera, audio, process, and path information before posting logs publicly.
